## 0. Роль и железные правила

Ты переписываешь TUI-интерфейс CLI-пакета Zerf (`cli/`), стиль — Claude Code.
Заказчик хочет строгий монохромный минимализм. Нарушение любого правила = переделка.

**ЗАПРЕЩЕНО:**
1. Эмодзи в интерфейсе (🚀⚡🤖🎙 и т.п.) — только глифы из таблицы §2.
2. `eval`, `Function()`, `child_process.exec` с конкатенацией строк — только `execFile`/`spawn` с массивом аргументов.
3. Новые npm-зависимости. Разрешены только уже установленные: `ink`, `ink-text-input`, `ink-spinner`, `react`, `chalk`, `commander`.
4. Цвета вне палитры §2.
5. Файлы длиннее 200 строк — дроби на модули.
6. Хардкод пользовательских данных (имена, chatId) — только из API.
7. Изменять `cli/src/api.ts` (транспорт) и бэкенд — только файлы из §3.
8. Дублировать логику: одна операция = одна функция в одном модуле.

## 2. Дизайн-система

### 2.1 Цвета (только эти)

| Токен | Значение chalk | Использование |
|-------|----------------|---------------|
| `c.text` | `chalk.white` | Обычный текст |
| `c.dim` | `chalk.gray` | Подписи, даты, счётчики |
| `c.accent` | `chalk.bold.white` | Заголовки, активные пункты, имя пользователя |
| `c.ok` | `chalk.green` | Только символ `✔` и слово успеха |
| `c.err` | `chalk.red` | Ошибки |
| `c.warn` | `chalk.yellow` | Предупреждения, просрочки |

Монохром — основа; зелёный/красный/жёлтый — только на статусах (1-2 символа), никогда для целых строк.

### 2.2 Глифы (заменяют эмодзи)

| Глиф | Значение |
|------|----------|
| `❖` | Логотип Zerf (перед именем, в баннере) |
| `●` | Выполняется (с spinner'ом) |
| `✔` | Успех |
| `✕` | Отмена/выход |
| `▸` | Пункт меню / ссылка |
| `◌` | Пустой чекбокс |
| `[✔]`/`[◌]` | Чекбокс задачи |
| `⬡` | ИИ думает |
| `✦` | Маскот: глаза-покой |
| `˘ᴗ˘` | Маскот: фокус |
| `⊙_⊙` | Маскот: тревога (дедлайн) |
| `✧ᴗ✧` | Маскот: радость |

### 2.3 Рамки и отступы
- Ширина контента: максимум 72 колонки.
- Разделитель: `─` × ширина терминала, цвет `dim`.
- Внутренние отступы: 1 пробел слева от контента, 1 пустая строка между блоками.
- Никаких boxen-рамок вокруг всего экрана. Рамка только у модальных списков (модель, друзья) — символами `┌─┐│└┘`, цвет `dim`.

## 3. Целевая структура файлов

```
cli/src/
  index.ts        — commander: разбор argv, запуск команд или REPL. Без логики UI.
  api.ts          — НЕ ТРОГАТЬ (транспорт: fetch, credentials, config).
  mascot.ts       — спрайты и глифы маскота. Дополнить по §6, если не хватает.
  local-cli.ts    — мост к внешним CLI. Переписать по §8.
  tui/
    theme.ts      — палитра §2.1, глифы §2.2, хелперы pad/truncate/divider.
    App.tsx       — корневой компонент: роутинг экранов, глобальные клавиши.
    Repl.tsx      — ТОЛЬКО цикл: prompt → dispatch → вывод лога. Хендлеры импортирует.
    Log.tsx       — компонент вывода истории (entries: user/assistant/system/error).
    StatusBar.tsx — нижняя строка: имя · тариф · дата · подсказка клавиш.
    commands/
      today.tsx   — экран «Сегодня»
      calendar.tsx— /cal 7 дней
      add.ts      — /add: парсинг, подтверждение, отправка
      done.ts     — /done: fuzzy-поиск, toggle
      note.ts     — /note
      focus.tsx   — /focus таймер
      model.tsx   — /model выбор
      settings.tsx— /settings
      friends.tsx — /friends
      limits.tsx  — /limits
      chat.ts     — /chat (текст в API ИИ)
      help.tsx    — /help и /keys
```

Правило: `Repl.tsx` ≤ 150 строк, каждый экран ≤ 150 строк. Общий код (fuzzy, countdown, progress) — в `theme.ts` или отдельном `utils.ts`.

## 4. Экраны (макеты 1:1)

### 4.1 Запуск без авторизации
```
 ❖ Zerf — второй мозг

 Вы не авторизованы. Запустить вход? [Y/n] y

 ✦ Требуется подтверждение в браузере:
   1. Откройте ссылку:  https://zeprh.vercel.app/cli-auth?code=A1B2-C3D4
   2. Нажмите «Подтвердить вход»
   Код действует 10 минут.

   ● Ожидание подтверждения…  (Ctrl+C — отмена)
```
После успеха:
```
 ✔ Добро пожаловать, {Имя} ({tariff})
```

### 4.2 Главный REPL (после запуска / после /clear)
```
 ❖ Zerf — второй мозт                 {Имя} · Plus · сб, 17 авг
 ────────────────────────────────────────────────────────────────
 ✦_✦  3 задачи на сегодня · 1 просрочена · стрик 5 дней

 › _
```
`›` — prompt (ink-text-input, цвет `accent`). Ввод пользователя дублируется в лог:
```
 › найди заметки про архитектуру
```
Ответ системы:
```
 ⬡ Ищу…
 ▸ 3 заметки:
   1. Архитектура бота        12.03 · 4 связи
   2. Масштабирование очереди 04.07
   3. Рефакторинг API         15.07
```

### 4.3 /today
```
 ❖ Сегодня · сб, 17 августа
 ────────────────────────────────────────────────────────────────
 ЗАДАЧИ
 [◌] Правки тарифов           сегодня · 19:00 · через 2 ч
 [✔] Созвон с командой        11:00
 [◌] Отчёт за неделю          просрочено на 2 дня   ← c.warn

 ПРИВЫЧКИ
 ▸ Чтение      ▓▓▓▓▓▓▓░░░ 7/10
 ▸ Спорт       ▓▓▓░░░░░░░ 3/10

 ▸ Enter — детали · Space — переключить · Esc — назад
```

### 4.4 Ошибка сети (единый формат для всех экранов)
```
 ✕ Нет соединения с сервером. Повтор через 5 с… (попытка 2/5)
```
После 5 неудач:
```
 ✕ Сервер недоступен. Проверьте интернет или zerver. /retry — повторить.
```

### 4.5 StatusBar (всегда внизу)
```
 {Имя} · {Plus|Pro|Corp|Free} │ /help — справка │ Ctrl+C — выход
```

## 5. Команды и slash (полный список, ничего сверх)

| Ввод | Действие | Ответ при успехе |
|------|----------|------------------|
| `/today` | Экран 4.3 | — |
| `/add <текст>` | Отправить `{action:'create', item:{type:'task', title}}` | `✔ Задача «X» — сегодня` |
| `/note <текст>` | То же, `type:'note'` | `✔ Заметка сохранена` |
| `/done <текст>` | Fuzzy по tasks → подтверждение Y/n → toggle_task | `✧ᴗ✧ Задача закрыта! Стрик: N` |
| `/cal` | calendar.tsx | — |
| `/focus [25]` | focus.tsx | По завершении: `✔ Сессия 25 мин завершена` |
| `/model` | Модальный список §7 | `Модель: X` |
| `/settings` | settings.tsx | — |
| `/friends` | friends.tsx | — |
| `/limits` | limits.tsx | — |
| `/chat <текст>` | sendAiQuery | Ответ ИИ в лог |
| `/clear` | Лог → экран 4.2 | — |
| `/help` | help.tsx: таблица команд + клавиши | — |
| `/exit` | Выход | — |
| Свободный текст | Тоже что `/chat` | — |

Fuzzy-поиск: подстрока без регистра; при 0 совпадений — `Не нашёл. /add «X» — создать?` Y/n.

| Клавиша | Действие |
|---------|----------|
| Enter | Отправить / подтвердить |

## 8. local-cli.ts (мост к внешним CLI)

- `detectInstalledClis()` — проверяет наличие бинарей (`which`/`where`) из белого списка: `claude`, `agy`, `opencode`, `gh`. Возвращает `{name, path}`.
- `runLocalCliBridge(name, args)` — **только** `spawn(detected.path, argsArray, {shell:false})`, таймаут 120 с, stdout/stderr транслируется в лог. Любой name не из белого списка → отказ `c.err('CLI не поддерживается')`.
- Никакой сборки командных строк.

## 9. Устойчивость

1. Все запросы — через `api.ts`; если он не имеет ретраев, обернуть в вызывающем коде: 5 попыток, backoff 1/2/4/8/16 с, только для сетевых ошибок (не для 4xx).
2. 401 → экран «Сессия истекла. zerf login — войти снова», токен удалить.
3. 403 (тариф) → сообщение из ответа API (там уже есть upgradeUrl).
4. Любой неописанный exception — поймать, вывести одну строку `✕ {message}`, не падать.

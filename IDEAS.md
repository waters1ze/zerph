## 1. 🖼️ SHARE-КАРТОЧКИ (PNG)

Красивые персональные картинки-карточки, которые бот/сайт отдаёт пользователю для соцсетей.

### Виды карточек
| Карточка | Содержимое | Виральный потенциал |
|---|---|---|
| **Недельный отчёт** | выполнено задач, часы фокуса, лучший день, streak | высокий — регулярный повод делиться |
| **Психологический портрет** | AI-анализ по задачам/заметкам: «архитектор хаоса», тип продуктивности, радар из 5 осей | максимальный — люди любят про себя |
| **Годовой отчёт** | Spotify-Wrapped стиль: топ-привычка, самый продуктивный месяц, тотальная цифра задач | взрывной, но раз в год |
| **Milestone-карточка** | «30 дней streak!», «100-я задача закрыта» | средний, триггер в моменте |

### Как работает
1. Триггер: еженедельный автопуш от бота / команда `/card` / кнопка в вебе / достижение цели.
2. Сервер собирает данные (AppActionLog, Task, Habit) → рендерит PNG.
3. Бот присылает картинку + кнопка «Поделиться». Watermark с ником бота → бесплатная реклама.

### Технически
- Рендер: `@vercel/og` (ImageResponse на satori) — нативно для Next.js/Vercel, без puppeteer.
- Шаблоны карточек — React-компоненты → легко темизировать под тему пользователя.
- Данные уже есть: AppActionLog, streakDays, Habit.streak.

## 2. 🔥 СТРИКИ ДРУЗЕЙ (соцслой)

Друзья видят стрики друг друга — социальное давление как в Duolingo.

- Раздел «Друзья»: аватар + 🔥 streak у каждого.
- Недельный лидерборд среди друзей.
- Приватность: тумблер «видно друзьям» (по умолчанию ON, отключаемый).
- Пуш-триггер: «У Маши стрик 12 дней, у тебя 7 — не отставай!»
- База готова: `streakDays` в TelegramChat, `Friendship` — нужен только API + UI-блок.

## 3. 💬 ZERF CHAT (мессенджер)

Стильнейший мессенджер, связанный с Zerf, но живущий отдельно.

### 3.1 Позиционирование
- **Отдельный проект на отдельном Vercel-деплое** + своя БД (второй Supabase-проект).
- Работает автономно И внутри экосистемы Zerf.
- Единый вход: авторизация через Telegram (тот же chatId).

### 3.2 Архитектура «полу-P2P» (важные нюансы)
Цель: не хранить переписки → юридическая устойчивость в РФ.

```
┌─────────┐   сигналинг (WebRTC offer/answer)   ┌──────────┐
│ Клиент A │ ◄──────────── сервер-ретранслятор ─►│ Клиент B │
│          │                                      │          │
│          │ ◄══════ сообщения напрямую P2P ════► │          │
└─────────┘   (WebRTC DataChannel, E2E-шифрование) └──────────┘
```

- **Контент сообщений**: P2P через WebRTC DataChannel, E2E-шифрование. Сервер контента не видит.
- **Fallback-relay**: если прямое соединение не пробилось (NAT/мобильные сети) — сообщения идут через сервер, но зашифрованы и не сохраняются (только форвардинг в память).
- **История**: только локально на устройствах (IndexedDB). На сервере — ничего.
- **В базе сервера**: аккаунты, публичные ключи, контакты, статусы доставки. Никакого текста сообщений.

⚠️ **Технические реалии, которые надо учесть заранее:**
- Vercel — serverless, постоянных WebSocket-серверов нет → сигналинг делать через Supabase Realtime, а relay при необходимости хостить отдельно (Railway/VPS + coturn TURN).
- P2P на мобильных в фоне нестабилен → relay-mode обязателен как основной путь доставки, P2P — оптимизация скорости/приватности.
- Это честная формулировка твоей идеи: «сервер — слепой курьер», блокировать нечего, хранить нечего.

### 3.3 Дизайн-цель «вау»
- Framer Motion: spring-анимации появления сообщений, плавные переходы экранов.
- Glassmorphism + мягкие градиенты, скелетон-лоадеры, анимированные реакции.
- Голосовые с живой волной, кружочки-видеосообщения, кастомные эмодзи-реакции с физикой.
- 60 FPS, микро-интеракции на каждое действие.

### 3.4 Темы
- Собственный тематизатор в мессенджере (несколько премиум-тем).
- Синхронизация: тема из основного Zerf подтягивается в мессенджер по аккаунту (и наоборот можно отключить).
- Общая дизайн-система Zerf: цвета, шрифты, радиусы — единый бренд.

### 3.5 Связка с Zerf (то, чего нет ни у одного мессенджера)
- Из любого сообщения → «Превратить в задачу» → улетает другу как Task (механика allowTasks уже есть).
- В профиле чата: стрик, выполненные задачи, активные цели друга.
- Утренний брифинг Zerf приходит туда же — один клиент на всё.

## Порядок реализации (предложение)
1. **Стрики друзей** — дёшево, база готова, быстрый эффект.
2. **Share-карточки** — виральность, тоже недорого (@vercel/og).
3. **Zerf Chat MVP** — отдельный большой проект: сначала relay-чат с E2E, потом P2P-оптимизация, потом анимационный полиш.

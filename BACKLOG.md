## 📰 ИИ-новости: ссылки на источники [ВАЖНО]
> Заметка добавлена: 2026-08-15

Нейронная сеть при генерации новостных дайджестов **обязана прикладывать ссылки** на те источники,
из которых она берёт информацию. Пользователь должен иметь возможность перейти по ссылке и
самостоятельно проверить факты.

**Требования:**
- При генерации новостного контента всегда включать `[источник](URL)` в конец каждой новости
- Если ИИ не может предоставить реальный URL — явно указывать что источник не доступен, не выдумывать ссылки
- Реализовать поиск актуальных новостей через web-search API (например, Serper/Brave Search/SearXNG) 
  и передавать найденные URL в промпт вместе с контентом

## 👤 Просмотр профилей на сайте и в TG мини-апп
> Задача добавлена: 2026-08-15

Реализовать просмотр профиля другого пользователя на веб-сайте и в Telegram Mini App.

**Логика:**
- Если у пользователя включен тумблер `allowTasks` (разрешены задачи от меня) — можно открыть его профиль и посмотреть задачи (с учётом приватности)
- Если тумблер выключен — кнопка/аватарка профиля заблокирована, профиль не открывается
- Приватные задачи (`isShared=false`) скрыты даже при открытом доступе

**Компоненты для разработки:**
- Страница `/profile/[chatId]` или модалка ProfileModal в веб-приложении
- В TG Mini App — кнопка с аватаркой пользователя в разделе «Команда»
- API endpoint `GET /api/profile/[chatId]` с проверкой allowTasks
- Защита: на сервере проверять allowTasks перед возвратом данных

## 🔒 Исправлен критический баг: задачи отправлялись ВСЕМ пользователям [FIXED]
> Исправлено: 2026-08-15

**Причина:** Функция `findFriendMatches` устанавливала `isAllowed=true` если пользователи состоят
в одном проекте или группе — даже если тумблер `allowTasks` был выключен. При `isPluralRecipient=true`
задача уходила ВСЕМ найденным совпадениям.

**Исправление:**
- ❌ Удалён обход через shared project / group membership
- ✅ Только `allowTasks=true` в дружбе (`Friendship.allowTasks`) даёт право на получение задач
- ❌ `isPluralRecipient` полностью удалён из ИИ-промпта и логики
- ✅ При нескольких совпадениях — всегда показывать кнопки выбора конкретного человека

## 🔑 Нормальный вход через Telegram в Safari на iPhone
> Задача добавлена: 2026-08-15

Сейчас токен одноразовый и ссылка открывается в браузере Telegram.
Необходимо: ссылка `/login` должна открываться в Safari и позволять пользователю
войти в аккаунт через браузер Safari на iPhone (не внутри Telegram WebView).

**Решения для изучения:**
- `tg://resolve?url=...` с параметром `&startapp=login`
- Использовать `window.open(url, '_blank')` вместо `Telegram.WebApp.openLink`
- Копирование ссылки с инструкцией «открыть в Safari»

## 📋 Общие задачи (Shared Tasks)
> Задача добавлена: 2026-08-15

Реализовать создание **общей задачи** для нескольких пользователей:
- Если пользователь говорит «дай нам с Лерой задачу сделать то-то» — система находит Леру,
  проверяет что у обоих включен тумблер `allowTasks`, создаёт общую задачу и отправляет
  двойное напоминание обоим участникам.
- Задача должна создаваться в обоих аккаунтах и быть связана общим `sharedTaskId`.
